# راهنمای انتشار «گفتمان دانش»

این پروژه یه سایت React با دیتابیس واقعی (Supabase) و پنل مدیریتِ همیشه‌فعاله. برای انتشار روی Netlify باید سه مرحله رو طی کنی: (۱) ساخت دیتابیس در Supabase، (۲) بارگذاری پروژه روی GitHub، (۳) اتصال به Netlify.

---

## مرحله ۱ — ساخت دیتابیس در Supabase (رایگان)

1. به [supabase.com](https://supabase.com) برو و با ایمیل یا گیت‌هاب ثبت‌نام کن.
2. یه پروژه‌ی جدید بساز (New Project) — یه رمز دیتابیس هم ازت می‌خواد، یادداشتش کن.
3. صبر کن پروژه ساخته بشه (حدود ۱-۲ دقیقه).
4. از منوی سمت چپ برو به **SQL Editor**.
5. فایل `supabase-schema.sql` (که در همین پروژه هست) رو باز کن، کل محتواش رو کپی کن، در SQL Editor پیست کن و دکمه‌ی **Run** رو بزن.
   - این کار جدول‌ها رو می‌سازه و محتوای اولیه (همون یادداشت‌ها و مجادله‌ی نمونه) رو وارد می‌کنه.
6. از منوی سمت چپ برو به **Project Settings → API**.
   - **Project URL** رو کپی کن → این می‌شه `VITE_SUPABASE_URL`
   - **anon public key** رو کپی کن → این می‌شه `VITE_SUPABASE_ANON_KEY`

---

## مرحله ۲ — بارگذاری پروژه روی GitHub

1. یه حساب رایگان در [github.com](https://github.com) بساز (اگه نداری).
2. یه ریپازیتوری جدید بساز (New repository)، مثلا با نام `gooftman-danesh`.
3. تمام فایل‌های این پوشه رو (به جز `node_modules` اگه بود) توی اون ریپازیتوری آپلود کن.
   - ساده‌ترین راه: از دکمه‌ی "uploading an existing file" در گیت‌هاب استفاده کن و فایل‌ها رو بکش و رها کن.

---

## مرحله ۳ — اتصال به Netlify

1. به [netlify.com](https://netlify.com) برو و ثبت‌نام کن (می‌تونی با حساب گیت‌هابت وارد بشی).
2. روی **Add new site → Import an existing project** بزن.
3. گیت‌هاب رو انتخاب کن و ریپازیتوری `gooftman-danesh` رو پیدا کن.
4. Netlify به‌طور خودکار تنظیمات build رو از فایل `netlify.toml` می‌خونه (نیازی به تغییر نیست).
5. قبل از دکمه‌ی Deploy، برو به بخش **Environment variables** و این دو مقدار رو اضافه کن:
   - `VITE_SUPABASE_URL` → همون Project URL از Supabase
   - `VITE_SUPABASE_ANON_KEY` → همون anon public key از Supabase
6. روی **Deploy site** بزن.
7. بعد از چند دقیقه، Netlify یه آدرس بهت می‌ده مثل: `https://gooftman-danesh-xyz.netlify.app`

سایتت الان زنده‌ست و در گوگل کروم (و هر مرورگری) برای همه قابل دسترسیه.

---

## بعد از انتشار

- **رمز پیش‌فرض پنل مدیریت**: `gooftman1404` — حتماً از تب «تنظیمات» توی پنل عوضش کن.
- **دامنه‌ی اختصاصی**: اگه بخوای به‌جای آدرس netlify.app یه دامنه‌ی خودت (مثلا gooftmandanesh.com) داشته باشی، از تنظیمات Netlify بخش **Domain settings** یه دامنه بخر یا دامنه‌ی خریداری‌شده‌ات رو وصل کن.
- **هر تغییری که در کد بدی و به گیت‌هاب push کنی، Netlify خودکار سایت رو دوباره می‌سازه.** ولی تغییرات محتوایی (یادداشت، مجادله، صداها) نیازی به این کار ندارن — مستقیم از پنل مدیریت ثبت می‌شن.

---

## نکته‌ی امنیتی مهم

پنل مدیریت با یه رمز محافظت می‌شه که به‌صورت هش‌شده در دیتابیس ذخیره می‌شه، اما بررسیِ درست بودن رمز در همون مرورگر انجام می‌شه (نه در یه سرور جدا). این یعنی این لایه‌ی محافظتی جلوی دیدن تصادفی پنل رو می‌گیره، ولی در برابر یه حمله‌ی هدفمند، امنیت درجه‌ی enterprise نداره. برای یه سایت شخصی این معمولاً کافیه، اما اگه محتوای حساس یا داده‌ی کاربران رو نگه می‌داری، بهتره از یه سیستم احراز هویت واقعی (مثل Supabase Auth) استفاده کنی.
